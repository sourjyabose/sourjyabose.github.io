Assuming you mean **.NET / ASP.NET** as a diploma-level university subject, here is a **last-minute exam revision in Question–Answer format**, focused on commonly asked theory questions.

# .NET Last-Minute Revision — Q&A

## 1. What is .NET?

**Answer:**
.NET is a software development platform developed by Microsoft. It provides an environment for developing and running applications such as:

* Desktop applications
* Web applications
* Mobile applications
* Web services
* Database applications

.NET supports languages such as **C#, VB.NET, and F#**.

---

## 2. What is the .NET Framework?

**Answer:**
The .NET Framework is Microsoft's framework for developing and executing applications on Windows.

It mainly consists of:

1. **CLR — Common Language Runtime**
2. **FCL — Framework Class Library**
3. **ASP.NET**
4. **ADO.NET**
5. **CTS — Common Type System**
6. **CLS — Common Language Specification**

---

## 3. What is CLR?

**Answer:**
**CLR stands for Common Language Runtime.**

It is the execution environment of .NET applications.

Main functions of CLR:

* Executes managed code
* Memory management
* Garbage collection
* Exception handling
* Security
* Thread management
* Type checking
* JIT compilation

**Exam line:**

> CLR is the runtime environment that manages and executes .NET programs.

---

## 4. What is managed code?

**Answer:**
Code that runs under the control of the CLR is called **managed code**.

Example:

```csharp
int x = 10;
Console.WriteLine(x);
```

The CLR manages memory, exceptions, security, and execution for this code.

---

## 5. What is unmanaged code?

**Answer:**
Code that executes outside the CLR is called **unmanaged code**.

Examples:

* C/C++ native code
* Windows API code
* Native machine-code libraries

The programmer or operating system is responsible for resources such as memory.

---

# 6. What is JIT?

**Answer:**
**JIT stands for Just-In-Time compiler.**

C# source code is first converted into **Intermediate Language (IL)**.

When the program executes, JIT converts IL into native machine code.

Flow:

```text
C# Source Code
      ↓
C# Compiler
      ↓
IL / MSIL
      ↓
JIT Compiler
      ↓
Native Machine Code
      ↓
CPU
```

---

# 7. What is MSIL/CIL?

**Answer:**
**MSIL** means Microsoft Intermediate Language.
Modern terminology is **CIL — Common Intermediate Language**.

It is the intermediate code generated by a .NET language compiler.

It is CPU-independent.

Example:

```text
C# → CIL → JIT → Machine Code
```

---

# 8. What is an assembly?

**Answer:**
An **assembly** is the compiled unit of a .NET application.

It generally contains:

* CIL code
* Metadata
* Manifest
* Resources

Assemblies usually have extensions:

```text
.exe
.dll
```

---

# 9. What is metadata?

**Answer:**
Metadata is information describing the types and members contained in an assembly.

It describes things such as:

* Classes
* Methods
* Properties
* Fields
* Data types
* References

The CLR uses metadata during execution.

---

# 10. What is CTS?

**Answer:**
**CTS stands for Common Type System.**

It defines how data types are declared and used in .NET.

It provides a common type system for all .NET-supported languages.

Main categories:

```text
CTS
├── Value Types
└── Reference Types
```

---

# 11. What is CLS?

**Answer:**
**CLS stands for Common Language Specification.**

It is a set of rules that .NET languages should follow so that code written in one .NET language can interact with code written in another.

For example:

```text
C# code
   ↓
VB.NET code
   ↓
Common .NET environment
```

---

# 12. Difference between CTS and CLS

| CTS                         | CLS                                        |
| --------------------------- | ------------------------------------------ |
| Common Type System          | Common Language Specification              |
| Defines all .NET data types | Defines language interoperability rules    |
| More comprehensive          | Subset of CTS                              |
| Used by CLR                 | Helps different .NET languages communicate |

**Remember:**
**CTS = Types**
**CLS = Language compatibility**

---

# 13. What is Garbage Collection?

**Answer:**
Garbage Collection is the automatic process of identifying and releasing memory occupied by objects that are no longer being used.

Example:

```csharp
MyClass obj = new MyClass();

obj = null;
```

If the object is no longer reachable, the garbage collector can eventually reclaim its memory.

**Advantage:** Programmer does not normally need to manually free managed memory.

---

# 14. What is an object?

**Answer:**
An object is an instance of a class.

Example:

```csharp
class Student
{
    public string name;
}

Student s = new Student();
```

Here:

* `Student` = class
* `s` = object/reference
* `new Student()` = creates an instance

---

# 15. What is a class?

**Answer:**
A class is a blueprint or template used to create objects.

Example:

```csharp
class Student
{
    public int rollNo;
    public string name;
}
```

---

# 16. What is inheritance?

**Answer:**
Inheritance allows one class to acquire properties and methods of another class.

Example:

```csharp
class Animal
{
    public void Eat()
    {
        Console.WriteLine("Eating");
    }
}

class Dog : Animal
{
}
```

Here `Dog` inherits from `Animal`.

```text
Animal
   ↑
  Dog
```

---

# 17. What is polymorphism?

**Answer:**
Polymorphism means **one interface/name having multiple forms**.

Two common types:

1. **Compile-time polymorphism**
2. **Run-time polymorphism**

### Compile-time

Usually achieved through method overloading.

```csharp
void Add(int a, int b)
{
}

void Add(int a, int b, int c)
{
}
```

### Run-time

Usually achieved through method overriding.

```csharp
class Animal
{
    public virtual void Sound()
    {
    }
}

class Dog : Animal
{
    public override void Sound()
    {
    }
}
```

---

# 18. What is encapsulation?

**Answer:**
Encapsulation means combining data and methods inside a class and controlling access to the data.

Example:

```csharp
class Student
{
    private int marks;

    public void SetMarks(int m)
    {
        marks = m;
    }
}
```

`marks` cannot be directly accessed from outside the class.

---

# 19. What is abstraction?

**Answer:**
Abstraction means hiding implementation details and exposing only necessary functionality.

Example:

```csharp
abstract class Animal
{
    public abstract void Sound();
}
```

The user knows that `Sound()` exists but the implementation can be provided by derived classes.

---

# 20. What are access modifiers in C#?

**Answer:**

Common access modifiers are:

| Modifier             | Meaning                                         |
| -------------------- | ----------------------------------------------- |
| `public`             | Accessible from anywhere                        |
| `private`            | Accessible only inside the class                |
| `protected`          | Accessible within class and derived classes     |
| `internal`           | Accessible within the same assembly             |
| `protected internal` | Combination of protected/internal accessibility |

---

# ASP.NET

## 21. What is ASP.NET?

**Answer:**
ASP.NET is Microsoft's framework for building **web applications and web services** using the .NET ecosystem.

It can be used to create:

* Dynamic websites
* Web applications
* APIs
* Web services

---

# 22. What is ASP.NET Web Forms?

**Answer:**
ASP.NET Web Forms is a web application framework that provides a visual, event-driven programming model for building web applications.

It uses:

* `.aspx` pages
* Server controls
* Code-behind
* Events
* ViewState

---

# 23. What is a server control?

**Answer:**
A server control is an ASP.NET control that executes on the server.

Example:

```aspx
<asp:Button
    ID="Button1"
    runat="server"
    Text="Click Me" />
```

The important attribute is:

```text
runat="server"
```

---

# 24. What is ViewState?

**Answer:**
ViewState is an ASP.NET mechanism used to preserve the state of controls between postbacks.

Example:

```text
Browser
   ↓
Request
   ↓
Server
   ↓
Response
```

ViewState stores information in the page so that control state can be restored after a postback.

---

# 25. What is PostBack?

**Answer:**
A PostBack occurs when a web page sends a request back to the same server to process an event or updated data.

Example:

```text
User clicks Button
        ↓
Browser sends request
        ↓
ASP.NET server processes event
        ↓
New page response
```

---

# 26. What is Code-Behind?

**Answer:**
Code-behind separates the presentation/design code from application logic.

For example:

```text
Default.aspx
       +
Default.aspx.cs
```

`Default.aspx` contains the UI, while `Default.aspx.cs` contains C# code.

---

# 27. What is a session?

**Answer:**
A session stores information associated with a particular user's interaction with a web application.

Example:

```csharp
Session["username"] = "Sourjya";
```

Later:

```csharp
string name = (string)Session["username"];
```

Session is useful for maintaining user-specific data between requests.

---

# 28. What is a cookie?

**Answer:**
A cookie is a small piece of data stored by the browser and associated with a website.

Example:

```csharp
Response.Cookies["username"].Value = "Sourjya";
```

Cookies are commonly used for:

* Preferences
* Tracking
* Authentication-related state

---

# 29. Difference between Session and Cookie

| Session                                       | Cookie                                     |
| --------------------------------------------- | ------------------------------------------ |
| Mainly maintained server-side                 | Stored on client/browser                   |
| Can store larger server-side state            | Limited size                               |
| More suitable for sensitive server-side state | Client can inspect/modify ordinary cookies |
| Associated with a session                     | Stored by browser                          |

---

# ADO.NET

## 30. What is ADO.NET?

**Answer:**
ADO.NET is the .NET technology used to access and manipulate data from databases and other data sources.

It provides classes for:

* Connecting to databases
* Executing SQL commands
* Reading data
* Updating data

---

# 31. What is SqlConnection?

**Answer:**
`SqlConnection` is used to establish a connection between a .NET application and a SQL Server database.

Example:

```csharp
SqlConnection con =
    new SqlConnection(connectionString);

con.Open();
```

---

# 32. What is SqlCommand?

**Answer:**
`SqlCommand` is used to execute SQL statements or stored procedures against a database.

Example:

```csharp
SqlCommand cmd =
    new SqlCommand("SELECT * FROM Student", con);
```

---

# 33. What is SqlDataReader?

**Answer:**
`SqlDataReader` provides a fast, forward-only, read-only way to retrieve data from a database.

Example:

```csharp
SqlDataReader dr = cmd.ExecuteReader();

while (dr.Read())
{
    Console.WriteLine(dr["name"]);
}
```

---

# 34. What is DataSet?

**Answer:**
A `DataSet` is an in-memory representation of data that can contain one or more tables.

It can work with data even when the database connection is closed.

---

# 35. Difference between DataReader and DataSet

| DataReader                               | DataSet                             |
| ---------------------------------------- | ----------------------------------- |
| Connected approach                       | Disconnected approach               |
| Forward-only                             | Can navigate/manipulate stored data |
| Read-only                                | Data can be modified                |
| Faster/lower memory generally            | More memory                         |
| Requires active connection while reading | Can work after connection closes    |

**Remember:**
`DataReader = Connected`
`DataSet = Disconnected`

---

# 36. What is a DataAdapter?

**Answer:**
A `DataAdapter` acts as a bridge between a database and a `DataSet`.

```text
Database
   ↕
DataAdapter
   ↕
DataSet
```

It can fill a DataSet from a database and propagate changes back to the database.

---

# Web Services

## 37. What is a web service?

**Answer:**
A web service is a software component that allows applications to communicate over a network using standardized protocols.

It allows different applications and platforms to exchange data.

---

# 38. What is SOAP?

**Answer:**
**SOAP = Simple Object Access Protocol.**

It is a protocol for exchanging structured messages between applications, commonly using XML.

Basic structure:

```text
SOAP Envelope
 ├── Header
 └── Body
```

---

# 39. What is REST?

**Answer:**
REST is an architectural style for designing networked applications, commonly using HTTP.

Common HTTP methods:

```text
GET     → Retrieve
POST    → Create/submit
PUT     → Replace/update
PATCH   → Partial update
DELETE  → Delete
```

---

# 40. Difference between SOAP and REST

| SOAP                        | REST                                          |
| --------------------------- | --------------------------------------------- |
| Protocol                    | Architectural style                           |
| Commonly XML-based          | Often JSON, but can use other representations |
| More heavyweight            | Generally simpler                             |
| Uses defined SOAP messaging | Uses HTTP semantics commonly                  |
| WSDL commonly used          | OpenAPI is commonly used for documentation    |

---
